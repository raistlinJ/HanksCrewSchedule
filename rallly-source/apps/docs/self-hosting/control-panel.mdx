The Control Panel is your central hub for administering your self-hosted Rallly instance. From here, you can manage users, activate your license, and configure instance-specific settings.

To access the Control Panel:

1.  Ensure your Rallly instance is running.
2.  Open your web browser and navigate to `/control-panel`.
3.  You may be prompted to log in if you haven't already. Only users with administrative privileges can access the Control Panel features.

## Initial administrator

The initial administrator is specified by the `INITIAL_ADMIN_EMAIL` environment variable during setup (see [Configuration](/self-hosting/configuration)).

To activate the initial administrator:

1.  Ensure the user account associated with the `INITIAL_ADMIN_EMAIL` has been created (e.g., by logging in once).
2.  Navigate to the Control Panel: `/control-panel`.
3.  The account is automatically assigned the administrator role and admitted to the Control Panel.

Existing administrators can grant the role to additional users from the **Users** section. Those users receive Control Panel access automatically; no separate claim step is required.

## Instance archives

Administrators can open **Instance archive** in the Control Panel to download a
portable JSON copy of the instance's users, spaces and memberships, polls and
poll groups, responses, comments, invitations, scheduled events, event types,
and sheets.

An archive can be restored from the same page. Restore replaces the existing
portable data in one transaction and signs everyone out. If any part of the
archive is invalid, the restore is rolled back and the existing data is left
unchanged. Instance configuration and licensing stay with the destination
installation.

<Warning>
  Archive files contain personal data, password hashes, poll responses, and
  private access links. Protect them like database backups. Restoring is
  destructive, so download a current archive or database backup first.
</Warning>

Instance archives intentionally exclude sessions, verification codes, OAuth
tokens, integration secrets, API keys, billing identifiers, licenses, and
uploaded file contents. Use the [CLI backup workflow](/self-hosting/management#backup-and-restore)
for complete disaster recovery, and back up object storage separately.

## Troubleshooting

If you see an **Administrator access required** message when visiting `/control-panel`, the account you are signed in with does not have the admin role. This usually means:

- The `INITIAL_ADMIN_EMAIL` environment variable is not set, or
- It does not match the email address of the account you are signed in with.

Update `INITIAL_ADMIN_EMAIL` to match your account's email address, restart your instance, and visit `/control-panel` again. Alternatively, an existing administrator can grant your account the admin role from the **Users** section of the Control Panel.
